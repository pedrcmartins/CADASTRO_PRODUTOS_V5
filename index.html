    Conceito Bootstrap
    O que é?

    O Bootstrap é uma biblioteca de CSS e JavaScript com componentes de interface prontos (botões, modais, alertas, toasts, grid, tabelas...). Em vez de escrever tudo do zero, aplicamos classes no HTML e o visual e o comportamento já vêm funcionando e responsivos.

    Como usamos neste projeto
    • Modal de confirmação: a classe .modal e o bootstrap.Modal substituem o confirm() antes de remover um produto ou limpar tudo. O JavaScript aguarda o clique em "Confirmar" ou "Cancelar".
    • Toasts: o componente .toast mostra avisos de sucesso (produto adicionado, atualizado ou removido) sem travar a tela.
    • Este modal: aberto apenas com atributos data-bs-toggle="modal" e data-bs-target, sem JavaScript extra.
    • Botões: as classes .btn, .btn-danger e .btn-outline-secondary padronizam as ações dos modais.
    Como usaríamos para acelerar ainda mais
    • Grid (.row / .col-md-4) no lugar do nosso grid-template-columns do formulário.
    • Formulário: .form-control e .is-invalid com .invalid-feedback para a validação visual dos campos.
    • Tabela: .table .table-hover .table-responsive para a lista de produtos.
    • Utilitários: .d-flex, .gap-3, .text-end e .mb-3 reduzem a quantidade de CSS próprio.
    Exemplo
    <button class="btn btn-danger"
        data-bs-toggle="modal"
        data-bs-target="#modal-confirmacao">
  Excluir
</button>
